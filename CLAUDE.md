## Figma work — always load the `gynger-figma` skill

For any Figma task (a figma.com link, Brisk Lunte 2026, the Design File, the DEV File, screens, flows, connectors or the design system audit), invoke the `gynger-figma` skill before the first Figma tool call and follow it. A `UserPromptSubmit` hook (`.claude/hooks/gynger-figma-reminder.sh`) reminds you automatically when a prompt mentions Figma.
